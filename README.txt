UTONWA — Amanze Chidinma Birthday Website
========================================

FILES
- index.html: website structure
- style.css: responsive design and animations
- script.js: gallery, music controls, sharing and wishes
- images/: Utonwa's separated photographs
- music/soft-instrumental.wav: original synthesized gentle piano-style instrumental included

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome.
3. For best results, use VS Code and the Live Server extension.

PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository named utonwa-birthday.
2. Upload all files and folders in this package (not just the ZIP).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. Wait for GitHub Pages to publish the URL shown there.

PERSONALIZE
- Replace the photos in images/ if you want different crops.
- The original gentle instrumental is included at:
  music/soft-instrumental.wav

Note: Music does not autoplay; visitors must press Play. This is expected browser behavior.
